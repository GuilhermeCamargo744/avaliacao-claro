# app-team-management

App mobile da avaliação (Expo + React Native). O caminho que eu deixei para quem
avalia é **Expo Go + Metro local** — sem emulador, sem EAS Build.

```bash
cd app-team-management
npm install
npx expo start
```

A API precisa estar no ar. O passo a passo completo, as decisões e o porquê do
Expo Go estão no [README da raiz](../README.md) e na [ADR 0010](../adr/0010-expo-go-para-validacao-local.md).
